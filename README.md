# HydraQuant - Smart Question Generator

HydraQuant is a Python-based quantitative aptitude question generator.

## Features

- Automatic question generation
- Three mathematical solvers
- Cross-validation of answers
- Automatic rejection of invalid questions
- HTML-based interactive quiz
- Detailed mathematical solutions

## Requirements

- Python 3.10 or newer

## Run locally

1. Clone the repository.
2. Create a virtual environment.
3. Run:

   python hydraquant.py

4. Select generation mode.
5. Open quiz_single.html in your browser.

## Technology

- Python
- HTML
- CSS
- JavaScript
